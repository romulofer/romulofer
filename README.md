## 🔭 Featured Projects

### 🦊 Developer tools
[**FoxGarden**](https://github.com/romulofer/foxgarden) · written in Rust (egui + tree-sitter)

A fast native IDE for Java, Kotlin, Python and the web stack, for Linux, macOS and Windows (English and Portuguese UI). Real language servers, debugger, git, Maven/Gradle, Spring awareness and static analysis, with languages added as extensions: [spring](https://github.com/romulofer/spring-foxgarden), [kmp](https://github.com/romulofer/kmp-foxgarden), [python](https://github.com/romulofer/python-foxgarden), [ts](https://github.com/romulofer/ts-foxgarden) and [svelte](https://github.com/romulofer/svelte-foxgarden).

[**FoxScreenshots**](https://github.com/romulofer/FoxScreenshots) · Kotlin Multiplatform

Screenshot capture and annotation tool for Windows, Linux and macOS. Local-first, no network calls, CI on every push.

[**foxrun-kotlin**](https://github.com/romulofer/foxrun-kotlin) · VS Code extension in TypeScript

One-click Run (and Debug) button over `main`, Kotlin syntax highlighting and autocomplete, with compiler errors in the Problems panel. The same idea for the Pulsar editor: [run-jvm-pulsar](https://github.com/romulofer/run-jvm-pulsar).

### 🤖 AI-assisted dev tooling
[**cyberfox**](https://github.com/romulofer/cyberfox) · [**cyberfox_web**](https://github.com/romulofer/cyberfox_web)

Tools that generate structured context files (`CLAUDE.md`, `.cursorrules`, `AGENTS.md`) for AI coding agents such as Claude Code - a Flutter/Dart app and a SvelteKit + Bun web rewrite ([try it](https://romulofer.github.io/cyberfox_web/)).
